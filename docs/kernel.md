# Kernel

The arena is the pool. There is no pager.
A pin is the snapshot. There is no version
chain. One writer. Readers do not wait.

Meta is a run of PUT and DEL. Compact is
the merge. That is the log-structured
file. It is not a second database.

The posting is ordered. Equality is a
point. A comparison is a range. There is
no leaf page, no split, no fill factor:
the tree is std. The body still does not
post.

Seed starts at the cheaper end. Unique
is one. An index is the posting length.
A type is the members. We do not enumerate
join trees. Two hops flip. That is the
cost.

The lease is the fence. A replica reports
a Pos. Lag is subtraction. There is no
vote. Raft was a week in 2019.

Grouped sync is a session. The default
still hits the platter. Uncommitted is
not on the log, so undo does not write
a CLR.

This file is the subtractions. The code
is what remains.
