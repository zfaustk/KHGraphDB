# Content

The graph is the skeleton. A document's body is
not. Posting lists take a name, a title, an id.
They do not take a page.

Type marks a key as content. The index refuses
it. A far cache of the other end of an edge
would take the title, not the body. Home keeps
the page. Replay restores both. Only home is
asked for the page.

This is why a shard can hold knowledge and
still move. The skeleton is small. The pages
stay with the address. MATCH still binds a
Khid on this box. A cite that leaves the box
is an Addr, not a second copy of the page.

Do not put a page in the posting list to make
search fast. Search is derived. The page is
the payload of the vertex that owns it.

The page is a blob. The WAL record names a
serial. Serials do not overwrite. A pin
still sees the old file. See `docs/write.md`.
