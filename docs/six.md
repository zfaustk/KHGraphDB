# Six

Home was the model in 2019. The log was
the truth. Meta was not the page. A Pos
was a prefix. This year that prefix is
the database.

A reader pins a Pos and replays only that
far. The writer keeps appending. There is
no lock: the reader never sees a record
the writer has not committed. Clone was
a picture of the arena. The picture is
not the store.

A keyed MATCH asks meta for addresses,
then runs at those homes in one round.
EXPAND does not walk off the box. The
page stays where the lease is.

The lease is who may append. Not a
majority. Two writers: the one without
the file does not write. Split reads
remain the deal.

A torn record is a bad CRC. Drop the
tail. Compact is a new generation; an
old Pos is void.

## Knowledge

A notebook is a home. Title is identity.
Body is content: it does not post, it
does not leave, a search does not need
it. Cite is an address. Fill a stub and
the reader has a name without the page.

That is the retrieval. Not a scan of
pages, not a bag of words on body. Find
the name, then the neighborhood.

A vector, if it comes, is another posting
list. Derived, droppable, not a pointer.
It does not replace Addr. The body still
does not move.

A program that answers from the graph
pins a Pos. Later it can prove which
notebook it saw. Permission is the home.
Do not copy the page in order to search
it.

Raft was a week in 2019 and then gone.
This file is that choice kept: fencing
by lease, isolation by prefix, query by
directory. The kernel was pointed here
before the words for it were common.
